# Bio Graph Frontend

README rapide frontend. Le guide complet du projet est dans ../README.md.

## Lancer
```bash
npm install
npm run dev
```

## Build
```bash
npm run lint
npm run build
```

## Variables .env
```env
VITE_NEO4J_URL=neo4j://127.0.0.1:7687
VITE_NEO4J_USER=neo4j
VITE_NEO4J_PASSWORD=your_password
```
